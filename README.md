## 10. الملفات والمكونات غير المكتملة فعليًا

يوجد في المستودع مجلدات معمارية تمثل أهدافًا مستقبلية، وبعضها يحتوي ملفات `index.ts` صغيرة فقط مع README يصف أن التنفيذ الإنتاجي لم يكتمل. أهمها:

- [ ] `ai/document-extraction` — موجود كنوع بيانات/نقطة تنظيم، وليس محرك استخراج إنتاجي كامل.
- [ ] `ai/evaluation` — ليس نظام تقييم إنتاجي كاملًا.
- [ ] `ai/finance-insights` — ليس محرك رؤى مالية كاملًا.
- [ ] `ai/local-models` — ليس طبقة نماذج محلية مكتملة.
- [ ] `ai/providers` — ليس نظام مزودي AI مكتملًا.

هذه المجلدات **لا يتم اعتبارها ميزات مكتملة** لمجرد وجود الملفات. كما أن `apps/worker/src/worker.ts` يشغّل حاليًا دوالًا تطبع رسائل sweep فقط؛ لا يوجد في هذا الملف تنفيذ فعلي لمعالجة طوابير الإشعارات أو المستندات.

كذلك توجد طبقتا API في الجذر (`api/`) و`apps/api`. توثيق المشروع يقول إن بعض مسارات الجذر باقية لتوافق Vercel، لكن يجب توثيق مصدر الحقيقة ومسار النشر لكل endpoint قبل حذف أو دمج أي منهما.

ملفات `docs/architecture.md` و`docs/database.md` و`docs/api.md` و`docs/deployment.md` حاليًا نصوص قالب عامة وليست توثيقًا فعليًا للبنية أو العقود أو النشر. كذلك عدد كبير من README داخل مجلدات الوحدات نصوص قالب؛ لا تُعد هذه الملفات دليلًا على اكتمال الوحدات.
