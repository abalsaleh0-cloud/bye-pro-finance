يوجد في المستودع مجلدات معمارية تمثل أهدافًا مستقبلية، وبعضها يحتوي ملفات `index.ts` صغيرة فقط مع README يصف أن التنفيذ الإنتاجي لم يكتمل. أهمها:

- [ ] `ai/evaluation` — ليس نظام تقييم إنتاجي كاملًا.
- [ ] `ai/finance-insights` — ليس محرك رؤى مالية كاملًا.
- [ ] `ai/local-models` — ليس طبقة نماذج محلية مكتملة.
- [ ] `ai/providers` — ليس نظام مزودي AI مكتملًا.

كذلك توجد طبقات API قديمة/موازية في الجذر (`api/`) إلى جانب `apps/api`. لم تُحذف تلقائيًا لأنها قد تكون جزءًا من نشر Vercel الحالي، ويجب توحيدها في مراجعة معمارية منفصلة قبل الحذف.
