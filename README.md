## 1. بطاقة المشروع

| البند | التفاصيل |
|---|---|
| اسم المشروع | BYE PRO FINANCE |
| الغرض | تطبيق إدارة مالية شخصية بواجهة عربية |
| الواجهة | React 19 + TypeScript + Vite |

## 7. إعداد البيئة

1. انسخ `.env.example` إلى `.env.local`.
2. اضبط `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` لقيم مشروعك.
3. ثبّت الحزم وشغّل أوامر الفحص أعلاه.
4. في Vercel اضبط متغيرات البيئة المطلوبة لكل من Preview وProduction ثم أعد النشر.

**الأمان:** لا تضع مفتاح `service_role` أو أي سر في متغير يبدأ بـ `VITE_` أو داخل Git. استخدم المفتاح العام المخصص للواجهة فقط، واحتفظ بالأسرار على الخادم.
